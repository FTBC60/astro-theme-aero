# Obsidian 每日日记模板

使用内置的“每日笔记”（Daily notes）创建日期文件夹与同名 Markdown，无需新增第三方插件。模板可使用 Obsidian 的日期变量，支持方式见[每日笔记](https://obsidian.md/help/plugins/daily-notes)和[模板变量](https://obsidian.md/help/plugins/templates)官方说明。

## 文件与链接设置

在 **设置 → 文件与链接** 核对：

| 设置 | 值 |
| --- | --- |
| 使用 Wiki 链接 | 关闭 |
| 新链接格式 | 相对于当前文件的路径 |
| 新附件的默认位置 | 与当前文件相同的文件夹 |
| 自动更新内部链接 | 建议开启 |

这样新加入的图片和 PDF 跟随日记文件夹，并以 `![照片](./photo.png)`、`[附件](./document.pdf)` 等标准 Markdown 引用。主题不解析 `![[photo.png]]` 等 Wiki 链接、笔记嵌入和 Obsidian 块 ID 引用（`#^block-id`）；已有这类链接需手动转换。设置行为见[官方说明](https://obsidian.md/help/settings)。

## 换行与分段

普通正文中，单次回车是软换行：生成的 HTML 文本中通常仍有换行字符，但浏览器会折叠显示为空格。空一行表示分成两个段落（`<p>`）。若要同一段内换行，在行尾添加反斜杠 `\` 或两个普通半角空格再回车，生成硬换行（`<br>`）。主题保持这些规则，不自动转换所有软换行。参见 [CommonMark](https://spec.commonmark.org/0.31.2/#soft-line-breaks)。

## 每日笔记与模板

1. 在本地 Vault 创建 `模板/` 文件夹，将同目录的[日记模板.md](日记模板.md)复制进去。使用源码模式编辑，保留日期变量外的双引号。
   在属性面板点击属性名称左侧图标，建议将 `title` 和 `slug` 的类型设为“文本”，`date` 设为“日期”，`publish` 设为“复选框”。Obsidian 按属性名称在整个 Vault 共享类型；主题读取笔记时会将无引号的日期形状标题和 slug 保留为字符串，因此重新保存属性后无需手动恢复引号。相关行为见[属性类型说明](https://obsidian.md/help/properties)。
2. 在设置中启用核心插件“每日笔记”。
3. 在“每日笔记”设置中填写：

| 设置 | 值 |
| --- | --- |
| 日期格式 | `YYYY-MM-DD/YYYY-MM-DD` |
| 新文件位置 | 留空，使用 Vault 根目录 |
| 模板文件位置 | 选择 `模板/日记模板.md` |

通过侧栏日历图标或“打开今天的每日笔记”命令触发创建，可为此命令设置快捷键。例如 2026-11-01 会创建：

```text
Vault/
├── 模板/日记模板.md
└── 2026-11-01/
    └── 2026-11-01.md
```

当天文件已存在时，命令打开现有笔记；模板只用于新建文件，不会覆盖已有正文。模板中显式 `slug` 保持文章地址为 `/posts/2026-11-01/`。

主题读取时，以下 Obsidian 保存形式与标题、日期和 slug 带引号的形式都能正常使用：

```yaml
---
title: 2026-11-01
date: 2026-11-01
publish: true
slug: 2026-11-01
---
```

解析采用 YAML Core，不启用隐式时间戳转换，`title`、`slug` 的日期文字保留为字符串；`date`、`updated` 继续由日期校验处理。标签的行内数组和多行列表均支持。数字、布尔值、数组或对象标题/slug 会报错，不会被强制转成字符串。模板里的日期变量继续保留双引号。修改后通过 Remotely Save 同步，再核对 NAS 上的 Frontmatter 并重新构建。

模板本身和新日记默认 `publish: false`：模板可能也被同步到 NAS，因此它必须作为未发布笔记跳过，保留的日期变量才能不影响构建。写完当天日记后，将该篇笔记的 `publish` 改为布尔值 `true`；下次成功构建、部署时才进入网站。只修改当天笔记，保留模板中的默认假值。
