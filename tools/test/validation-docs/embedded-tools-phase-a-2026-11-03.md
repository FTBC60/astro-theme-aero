2026-11-03（America/Los_Angeles）。基线 `static` / `ffd0518`。**阶段 A 已执行；基础能力通过，但移动兼容性存在未通过项。正式工具编译尚未实现，不能据此宣布功能可稳定发布。**

证据：[脱敏结果 JSON](embedded-tools-phase-a-2026-11-03.json)；复现：[实验脚本与说明](../embedded-tools/README.md)；方案：[当前草案](../../../docs/architecture/embedded-tools-proposal.md)；[ADR-0014 提议](../../../docs/adr/0014-static-embedded-tools.md)。

## 1. 实验范围

复制当前主题 src 与布局到隔离目录，用手写 iframe 页面验证未来编译输出的运行条件。保留现有 ClientRouter、音乐持久化和样式，不添加正式工具脚本。所有公开测试资源使用合成内容和真实 2048 单文件样本，没有部署作者 Vault、实际头像、音乐或凭据。

现有 `resolveNoteAsset` 用于样本路径映射，但手写 iframe 及测试资源复制不等于工具 Markdown 插件已实现。也没有将开发服务的 HTML MIME、Publisher 编译、正式发布筛选或 NAS 容器更新算作本次通过项目。云端更新/删除实验直接改写隔离站点产物，证明的是完整版本部署的静态资源行为。

环境：Windows；Node 24.22.1；Astro 7.3.8；Wrangler 4.152.0；compatibility_date `2026-10-25`；`force-trailing-slash`；`not_found_handling: none`。没有升级依赖或修改现有站点配置。

样本：`2048/2048.html` 的原字节快照，21,662 字节；SHA-256 `e83f59faf0d6f0ae527e827d4298b3ebd9f8dd1711ff4ff3fb7ab9ecb86f42c7`。核对复制产物摘要一致。

浏览器：Chrome `148.0.7778.179`；与驱动匹配的 Windows WebKit `27.2`，Playwright `1.65.0-alpha-2026-10-30`。触屏异常另用运行时自带 Playwright `1.62.1` 对照。Windows WebKit 不是 iPhone Safari；手机视口/触屏模拟不等于实体设备。

## 2. 权限与基本操作

固定 `sandbox="allow-scripts allow-downloads"`：

- Chrome 与 WebKit 均通过实际文件选择、JSON 导入、连续两次下载、文件名、导出后重新导入及错误导入不改局的检查。
- 无存储权限仍正常启动和操作；工具提示无法自动保存，允许手动导出。
- 真实浏览器中读取父 DOM、Cookie、localStorage 及修改顶层导航均被阻止。
- scripts-only 对照可以运行游戏，但 JSON 下载被阻止。
- 直接访问 HTML 时可以使用正常来源的 localStorage，确认 iframe 属性不会自动保护独立 URL。

结论：保留双权限；不为了文件操作增加 `allow-same-origin`、表单、弹窗或其他权限。首版不实现工具自声明授权。用户点击才导出是工具规范，`allow-downloads` 本身不是用户手势或 JSON 格式白名单。

核心场景包含直达、真实 ClientRouter 切页（用同一 document 标记和 after-swap 核验）、屏幕外 lazy iframe 滚入视口、离开销毁、返回重新初始化、历史前进/后退、共享中文路径、键盘进出 iframe 和 390/280px 宽度。音乐检查使用合成 WAV，核对 audio 节点身份、播放状态和时间连续。

Chrome 的实测不需要 `embedded-tools.ts`。因此不预加重建逻辑或生命周期控制器，也不引入 `transition:persist` 或父子消息协议。

### WebKit 未通过项

Windows WebKit 原生切换到带长间隔的 lazy 工具页时发生页面进程崩溃。用全新进程单独执行仍复现；注入旧版 iframe 重建适配后仍失败。

移除 iframe、保留同样长页面的对照也崩溃，说明问题并非该 HTML 工具独有。不能由此归因到某个主题模块、所有 WebKit 或 iPhone Safari。强制关闭原生 View Transition 的诊断对照没有取得有效通过结果（等待导航事件超时），不能作为已经验证的修复方案。

一次完整 WebKit 连续测试在崩溃后出现多项连锁失败；不将这些都计作不同功能缺陷。另开的云端 7 项子集通过证明文件操作与普通切页可行，但不能覆盖长页或历史导航矩阵。完整 WebKit 兼容性仍待验。

## 4. 窄屏、键盘与触屏限制

- Chrome 与 WebKit 在父视口 390/280px、iframe 高度 480px 下，工具内部未横向溢出，内部滚动可到达文件按钮，鼠标/键盘下载有效。
- Tab 与 Shift+Tab 可进入并退出 iframe，没有发现键盘陷阱。
- WebKit 触屏模拟的方向按钮与导出检查通过。
- **Chrome 触屏模拟未通过：** 方向按钮收到 pointerdown/touchstart/pointerup/touchend，但合成 click 的目标变成 DIV，对局未移动。等待 UI 状态、滚动稳定后轻点、iframe 改为 820px，以及换用 Playwright 1.62.1 都未取得通过。
- 同一 Chrome、同一操作直接访问工具 HTML 时通过。当前证据把复验范围收敛到 iframe 中的触屏点击链路，但不能判定是真实 Android 缺陷、自动化坐标问题还是其他浏览器行为。

结论：480px 保持暂定，不因这次问题自动加高容器、开放权限或增加全局 touch 代理。正式移动支持需要复验实体手机，并用最小 iframe/按钮对照定位 Chrome 输入问题；WebKit 长页需要在匹配的稳定 Safari 环境复验。不能把宽度适配通过写成“移动端全面通过”。

## 5. 本地与实际 Cloudflare 路由

根路径与 `/blog/` 各构建一次，在测试主机上按相应位置挂载。工具保持完整 `.html` URL；包含前缀，不把源 MD 的相对路径直接输出给 iframe。

| 检查 | 结果 |
| --- | --- |
| 本地初始资源路由 | 38 项断言通过，另有 10 项大小写观察、16 项同名路径观察 |
| 云端初始版本 | 38 项断言通过；同上观察项目 |
| 云端更新版本 | 38 项断言通过，字节摘要和内容标记均为新版 |
| 云端撤回版本 | 38 项断言通过，相关旧工具地址均未返回旧内容 |

云端三轮共 114 项断言通过。每次请求记录初始路径、全部重定向、最终路径、状态、Content-Type、字节摘要和内容标记；不单凭状态码判断。被撤回的游戏和共享工具的扩展名、无扩展名、尾斜杠、index 等已记录地址均得到 404。此结果不撤回访客已有的缓存或下载副本。

普通 `.html` 在没有同名文件夹入口时规范化到尾斜杠 URL。**同时存在 `tool.html` 和 `tool/index.html` 时，本次实际行为不同：**

| 请求 | 返回内容 |
| --- | --- |
| `tool.html` | 对应平面 HTML 文件，200，未重定向 |
| `tool/` | `tool/index.html`，200 |
| `tool`、`tool/index.html` | 重定向到 `tool/`，返回文件夹入口 |

工具与真实 Astro 文章路径并存的对照也得到这个结果。因此，不能按去掉 `.html` 后的名称一律判冲突；暂不新增通用路由检测或共享 URL 注册系统。继续生成完整附件 URL 并保留现有文件冲突检查，针对已知并存场景补回归；其他托管策略不由本次结果保证。

大写 `.HTML` 原地址正常返回 HTML，但没有自动生成小写 `.html` 那套无扩展名别名。保留源文件大小写，不自动改名或猜测规范化 URL。

### 字面百分号文件名的部署限制

第一份带 `%` 文件名的站点被云端上传会话拒绝，错误 `10304: Manifest path must be URI encoded`，本地服务并未发现这个问题。随后用同一固定 Wrangler 做独立最小部署：

| 文件名 | 上传结果 |
| --- | --- |
| `plain.html` | 通过 |
| `工具 空格.html` | 通过 |
| `percent%name.html` | 被 API 拒绝，10304 |
| `hash#name.html` | 通过 |

主实验排除字面 `%` 后成功部署，中文、空格、`#` 的路径及字节核对均通过。源码中引用 `#` 仍需按既有规则写成 `%23`。

首版建议对工具**输出相对路径中的字面 `%` 字符**在构建前报错，并提示作者改名；不是禁止 URL 中正常的百分号编码。不自动重命名附件，不升级 Wrangler 或重写通用上传器。普通附件现有行为属于已有发布链路的兼容问题，不能在阶段 A 顺带改写。

## 6. 收敛结论与未覆盖项

已具备依据的契约：单文件 HTML、固定脚本＋下载、根内相对引用、文章所属副本、编译器生成带 base 的完整 URL、保留原字节、当前静态托管正常更新/删除、无需预加工具生命周期脚本。

需要保留的限制：只托管作者审查的内容；直接 URL 不继承 iframe sandbox；不保证禁止联网或执行配额；不承诺存储和跨页状态；当前固定上传链路的工具路径不包含字面 `%`。

未完成：实体手机、实际 Safari、Chrome iframe 触屏点击定位、WebKit 长页稳定性，以及阶段 B/C 的 Markdown 编译接入、dev MIME、实际附件复制/发布筛选回归、NAS/只读挂载和正式部署。阶段 A 结束不表示这些项目通过。

本轮新增实验脚本、样本快照、结果与设计文档。正式 `src/`、发布工具、package/锁文件与当前博客没有修改。两次成功 Astro 构建使用隔离副本；没有用静态模板替代主题布局来证明切页行为。

本次新建的主测试 Worker 与文件名测试 Worker 已全部删除。原始日志和截图留在本机忽略的 `.astro`，提交材料只保留脱敏证据。初始驱动不匹配、测试同步等待误判和本地兼容日期设置在正式记录前纠正，不计作主题功能缺陷。
