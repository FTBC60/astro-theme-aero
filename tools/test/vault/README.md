# 完整 Vault 验收样本 / Complete Vault fixture

`Notes/` 是只含合成内容的测试 Vault，可整目录复制到独立的 NAS 测试目录。不要覆盖自己的真实日记。它不会随默认 `src/content/posts/` 自动发布。

`Notes/` contains synthetic content only. Copy it to a separate test directory; keep your real notes separate. The default content directory does not publish this fixture.

包含同目录 SVG、有效 PDF、中文和空格文件名、子目录笔记、共享附件、未引用附件、私人笔记、模板和隐藏文件。图片/PDF 中的文字只是测试标记。

Includes local SVG images, a valid PDF, Chinese filenames with spaces, nested notes, shared and unused attachments, private notes, templates, and hidden files. Image/PDF text is test content.

操作、预期路径及撤稿验收见[中文指南](../validation-docs/zh-CN/VAULT-VALIDATION.md) / [English guide](../validation-docs/en/VAULT-VALIDATION.md)。
